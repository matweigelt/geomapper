A GRACE workflow

From a monthly solution to a figure at the width a journal asked for.

1. Read the field

G = geo.readGrid("ewh_2003.nc", Units = "cm");

2. Choose a projection

crs = geo.crs("mollweide");

3. Draw it

H = geo.map(G, crs, Colorbar = struct(Label = "EWH (cm)"));

4. Mark what is significant

H = geo.map(G, crs, Stipple = struct(G = mask));

5. Put a track on it

H = geo.trackmap(T, crs, Track = struct(Style = "bicolor"));

6. Compare two epochs

H = geo.panel(spec, Layout = [1 2]);

7. Export at journal size

geo.export(H.Figure, "fig3.pdf", Width = 17);

Two things worth knowing before you start

Equal-area or the comparison is wrong. A mass anomaly is read by area. See choosing a projection.

A shared colour scale, or the panels are not comparable. geo.panel shares one by default across map tiles, because a reader assumes it.
